# Workshop :: API Development with AI

## Workflow (Human in the Loop)
```
Specification
     ↓
Tests / Evals
     ↓
Implementation
     ↓
Verification
```

## List of skills
- Writing API specifications
- Writing tests and evaluations
- Implementing API endpoints
- Verifying and debugging code

## 2. Tests / Evals

## 3. Implementation
```
/api-implementation-generator implement feature weather
```

## 4. Verification
